# Literature Subsystem (`research/literature/`)

Stores verified paper summaries, bibtex references, and systematic literature review notes.

## Guidelines
1. Do not add unverified or fabricated citations. Include valid DOIs or arXiv links for all entries.
2. Group reviews by sub-domain: `edge_ai`, `industrial_inspection`, `3d_print_defects`, `model_compression`, `adaptive_inference`.
