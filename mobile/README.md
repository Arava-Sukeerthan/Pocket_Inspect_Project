# Mobile Client Module (`mobile/`)

Houses native/cross-platform application source code for running PocketInspect directly on physical Android smartphones.

## Key Focus Areas
- Android Camera2 API frame acquisition and exposure management.
- On-device TFLite / ONNX Runtime execution via native NDK / C++ / Java bindings.
- Thermal sensor listener and battery discharge telemetry logging.
- Touch-screen user interface for operator inspection feedback.
