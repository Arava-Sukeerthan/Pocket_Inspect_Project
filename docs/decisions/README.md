# Architecture Decision Records (ADRs) (`docs/decisions/`)

Documents critical design and architectural choices made throughout the project life cycle.

## Format (ADR Template)
- **Title**: ADR-001: Short Decision Title
- **Status**: Proposed / Accepted / Superseded
- **Context**: Problem description and technical constraints.
- **Decision**: Chosen solution and rationale.
- **Consequences**: Tradeoffs, risks, and impact.
